# MMA Conditioning — Training Generator

Gerador de treinos em português, com identidade visual preta e roxa, feito em HTML, CSS e JavaScript puro.

## Recursos
- Geração aleatória de Full Body, Core Blast, Leg Day e MMA Conditioning.
- Configuração de duração, quantidade de exercícios, formato e descanso.
- Aquecimento e finalização opcionais.
- Evita repetir o mesmo exercício dentro da sessão e tenta variar categorias.
- Copiar a ficha e imprimir/salvar como PDF pelo navegador.
- Layout adaptável para celular e computador.

## Executar
Abra `index.html` em um navegador.

## Publicar com GitHub Pages
1. Entre em **Settings** deste repositório.
2. Abra **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)`; salve.
5. Aguarde o GitHub Pages concluir a publicação.

O site usa um único `index.html`, então não precisa de build ou dependências.

## Aviso
Ferramenta de apoio ao treinador. Revise volume, técnica, cargas e adequação dos exercícios antes de aplicar o treino. A duração selecionada é uma meta, não uma cronometragem exata.
